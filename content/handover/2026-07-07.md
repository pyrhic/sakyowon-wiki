## 스킬 (다음에 재사용할 만한 기술)
- **hwp 자동화는 "표시자 심고 찾아바꾸기"가 정답**: 처음부터 표를 코드로 그리려 하면 병합/배경색 API가 불안정해서 실패함. 실제 사용 중인 양식 파일에 `{{PERIOD}}` 같은 고유 문자열을 한 번 심어두고, 매주는 텍스트 치환만 하면 훨씬 안정적
- **Cloudflare D1 + Functions + Workers AI**로 Supabase/외부 API 없이도 완결된 백엔드를 만들 수 있음 (계정 하나로 DB+서버+AI 다 됨)
- **Google Cloud Shell + `cloudshell download`**: 서비스 계정 생성처럼 반복적인 GCP 콘솔 클릭을 gcloud 스크립트 한 번으로 압축 가능. 키 파일은 터미널에서 복사하지 말고 `cloudshell download`로 내려받게 하면 실수가 줄어듦
- **PowerShell/curl로 한글 보낼 때**: 인라인으로 `-d '...'`에 한글 넣으면 인코딩 깨짐. 파일로 저장 후 `--data-binary @파일`로 보내야 안전함

## 레슨 (오늘 겪은 문제와 원인)
- **Cloudflare 환경변수/바인딩은 추가 후 반드시 재배포해야 적용됨** — 안 하면 기존 배포는 계속 예전 상태로 동작해서 원인 파악이 헷갈림
- **구글시트에 "새 행 추가(append)"는 위험함**: 시트가 연간 날짜가 미리 채워진 템플릿이면, append는 엉뚱한 위치(맨 끝)에 잘못 삽입될 수 있음. 날짜로 기존 행을 찾아 특정 셀만 업데이트하는 게 안전
- **클라우드 루틴(Claude 세션)은 조직 네트워크 정책으로 외부 API(Supabase, GitHub) 접속이 막힐 수 있음** — 팀 계정 환경에서는 계산까지만 클라우드에 맡기고, 실제 저장/후처리는 로컬(또는 개인 세션)에서 하는 구조로 우회함
- **Google Cloud Shell 튜토리얼의 "시작" 버튼은 명령어를 입력만 해주고 Enter는 안 눌러줌** (보안 정책, 바꿀 수 없음) — 여러 번 누르면 텍스트가 계속 이어붙여지므로 한 번만 누르고 직접 Enter를 눌러야 함. 이 부분 UI가 이규영 환경에서 불안정하게 동작해서 다음에 다시 점검 필요
